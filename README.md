# 🌸 Iris Flower Classification using SVM

A Machine Learning project that classifies iris flower species based on petal and sepal measurements using Support Vector Machine (SVM).

---

## 🚀 Live Project Overview

This project predicts whether a flower belongs to:
- Iris-setosa
- Iris-versicolor
- Iris-virginica

based on 4 input features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

---

## 📸 Sample Output

```
Average Cross-Validation Accuracy: 96.67%

Input: 5.8, 3.5, 3.7, 1.3
Prediction: Iris-versicolor
```

---

## 💡 Key Features

- Achieved **96.67% accuracy** using 5-fold cross-validation  
- Implemented **Support Vector Machine (SVM)** for classification  
- Applied **feature scaling** using StandardScaler  
- Used **Label Encoding** for categorical conversion  
- Performed **Exploratory Data Analysis (EDA)**  
- Built an **interactive prediction system**  

---

## 🛠️ Tech Stack

- Python  
- Pandas

---

## ⚙️ How It Works

1. Load dataset (Iris dataset)  
2. Preprocess data:
   - Label Encoding  
   - Feature Scaling  
3. Train model using SVM  
4. Evaluate using Cross-Validation  
5. Predict species based on user input
